Auto-sends your Twitch link into every League of Legends champ select — automatically.

No more typing your channel link every single game. This runs quietly in the background and drops your message into chat the moment champ select starts, and again after the game ends.

What you get:
A ready-to-run Windows app. Download, double-click, done — no Python, no install, no terminal.

How it works:
Open League and log in. Type your message once. Click Start. That's it — it keeps sending it every game until you stop it.

Built on Riot's own local client API — the same category of tool as Blitz and Porofessor. Doesn't touch your game files, memory, or input.

Note: first launch may show a Windows "unknown publisher" warning — that's normal for small independent tools, just click "Run anyway."
